# AllProject

## ¿Qué es?
Es una vista global que agrupa todas las clases del sistema en un solo lugar, organizadas por tipo de componente sin separar por microservicio.

## ¿Para qué sirve?
Permite ver de un vistazo todas las clases que existen en el sistema completo. Es útil para entender el alcance total del proyecto antes de entrar al detalle de cada módulo.

## ¿Qué muestra?
- Todas las Entity del sistema juntas
- Todos los IRepository juntos
- Todos los IService juntos
- Todos los Service juntos
- Todos los Controller juntos
- Todos los DTO e IDTO juntos
- Todos los Utils juntos

## En el proyecto SENA
AllProject muestra en un solo lugar todas las clases de ms-horarios, ms-catalogos, ms-security, ms-disponibilidad, ms-observaciones, ms-reportes, workflow-api y workflow-worker sin separarlas por microservicio.
