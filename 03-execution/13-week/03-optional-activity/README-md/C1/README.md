# C1 — System Context

## ¿Qué es?
Es el primer nivel del modelo C4. Muestra el sistema completo visto desde afuera, sin entrar en detalles técnicos. Responde la pregunta: **¿qué hace el sistema y quién lo usa?**

## ¿Para qué sirve?
Permite entender el sistema de un vistazo. Es el diagrama más general y está dirigido a cualquier persona, incluso sin conocimientos técnicos.

## ¿Qué muestra?
- Los usuarios que interactúan con el sistema
- El sistema como una sola caja
- Los sistemas externos con los que se conecta

## En el proyecto SENA
El sistema de gestión de horarios recibe peticiones del Coordinador Académico, el Instructor y el Admin de Ambientes, y se conecta externamente con Camunda y la base de datos.
