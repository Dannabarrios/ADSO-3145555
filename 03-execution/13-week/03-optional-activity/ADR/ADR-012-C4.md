# ADR-012 — Modelo C4

## Contexto
El equipo necesitaba una forma estándar de documentar la arquitectura comprensible tanto para personas técnicas como no técnicas.

## Decisión
Se adoptó el modelo C4 de Simon Brown para documentar la arquitectura en 4 niveles: System Context, Container, Component y Code.

## Razón
El modelo C4 permite comunicar la arquitectura a diferentes audiencias usando el nivel de detalle apropiado para cada una.

## Consecuencias
La arquitectura queda documentada de forma clara y progresiva. Cualquier nuevo integrante puede entender el sistema leyendo los diagramas de afuera hacia adentro.
